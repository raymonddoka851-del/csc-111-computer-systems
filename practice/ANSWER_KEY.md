# CSC 111 · Worked answer key

Use these as model reasoning, not text to memorize. Equivalent wording is acceptable when the concepts and steps are correct.

## 01 · Foundations

**Q01.** Input is the three typed scores and the instruction to calculate a mean. Processing adds the values and divides by three. Output is the displayed mean. Storage is the saved file or record that retains the result after the program closes.

**Q02.** From right to left, the place values are 1, 2, 4, 8, 16. Thus `10110₂ = 1×16 + 0×8 + 1×4 + 1×2 + 0×1 = 22₁₀`.

**Q03.** First-generation computers used vacuum tubes; they were large, hot, power-hungry, and required considerable maintenance. Fourth-generation systems use microprocessors, putting the CPU on a chip; this enabled smaller, cheaper personal computers with much greater capability.

## 02 · Hardware

**Q04.** RAM is temporary, fast working memory used by running programs; disk/SSD storage keeps files persistently. Free disk space does not indicate available RAM. Many open programs may exhaust working memory and cause slowdowns, so insufficient RAM is a likely bottleneck (though CPU or other causes are also possible).

**Q05.** Use OMR for a carefully designed answer sheet with filled marks. Use OCR to recognize the printed paragraph and turn it into editable characters.

**Q06.** Keyboard (input) sends the key data to the system; data/instructions are held in RAM; CPU control and arithmetic/logic units execute the calculation; the display (output) shows the result. If the result is saved, secondary storage retains it.

## 03 · Software

**Q07.** Windows is an OS, therefore system software. A printer driver is system software that lets the OS control a device. A backup utility is system software/utility software that supports maintenance. Excel is application software for spreadsheet tasks.

**Q08.**

```text
INPUT C
F = C * 9 / 5 + 32
OUTPUT F
```

For `C = 20`: `20 × 9 / 5 + 32 = 36 + 32 = 68°F`. Include parentheses if the chosen language’s operator precedence requires them: `(C * 9 / 5) + 32`.

**Q09.** Warning signs include an unexpected attachment and pressure to act immediately; sender/address mismatch or a request for credentials/payment are additional signs. Do not open or reply; verify with the supposed sender through a separate trusted channel, then report/delete according to policy. If opened, notify support promptly and follow incident instructions.

## 04 · Windows and files

**Q10.** Open File Explorer → Documents → New folder → name it `CSC111` → open it → create `Week1` → open that folder. In Word choose Save As, browse to `Documents\CSC111\Week1`, enter `review.docx`, and save. Verify the title/filename and location in the Save dialog or File Explorer; reopening the file is a useful check.

**Q11.** Copy creates a separate file while retaining the original. Move relocates the item to another location. A shortcut points to the original and is not an independent copy. Copy is the method that preserves the original and creates another file.

**Q12.** Lock protects the current signed-in session and leaves programs running; sign out closes the user session and programs; restart closes and reloads the OS. For a brief absence, Lock is appropriate.

## 05 · Internet and email

**Q13.** The Internet is the global system of connected networks. The Web is a service running over it, made of linked pages and resources. A browser requests and displays Web content. A search engine indexes content and helps locate pages; it is accessed using a browser.

**Q14.** Check (1) who authored/published it and their relevant expertise, (2) evidence and links to original data, (3) date and whether it is current, (4) purpose, funding, or possible bias. Compare independent authoritative sources and cite the source actually consulted. Do not treat high search ranking as proof of reliability.

**Q15.** Use Bcc to conceal recipients’ addresses from one another (or use an approved mailing-list service). Before sending, verify the address/list, subject and message, attachment and its privacy, and that Bcc is populated correctly; send a test to yourself if appropriate.

## 06 · Word processing

**Q16.** Create a blank document and Save As `.docx` in the correct folder. Type the title and use Heading 1 for the two section headings; use Normal for body text. Insert page numbers using Insert → Page Number. Check page layout and print preview, then save and verify the filename/location.

**Q17.** Heading styles create consistent formatting and document structure, allowing navigation and an automatically generated table of contents. Page breaks place content reliably on a new page; repeated Enter presses can shift unpredictably when earlier content changes.

**Q18.** Prepare a template and clean spreadsheet (one recipient per row, clear field headings); select Mailings → Start Mail Merge → choose recipients → insert fields → preview several letters → finish/print or send. Check recipient accuracy and sample personalized results. Also confirm permission/privacy, correct attachment/content, and test delivery before sending to everyone.

## 07 · Spreadsheets and Excel

**Q19.** Sum formula: `=SUM(B2:B5)` → `12+18+15+5 = 50`. Average formula: `=AVERAGE(B2:B5)` → `50/4 = 12.5`.

**Q20.** In `D2`, use `=C2*$B$1`. `$B$1` is absolute so it does not move when copied. In `D3`, the formula becomes `=C3*$B$1`. For the given row, tax is `250 × 0.16 = 40`.

**Q21.** Sorting only one column breaks the record associations, so names no longer match their original row data. Select the whole table, indicate that it has headers if prompted, then sort by surname. A bar/column chart is suitable for comparing four product sales.

## 08 · Presentations and networks

**Q22.** Example: (1) title and purpose, high-contrast large title; (2) common risks, short list with one simple icon; (3) prevention steps, numbered sequence; (4) response/reporting and takeaway, one clear action. Keep one main idea per slide, use a consistent theme, cite image/data sources, and rehearse. Other sensible four-part outlines earn credit.

**Q23.** It is a LAN because it covers the office/campus site. A switch connects local devices and forwards traffic within the LAN; a router directs traffic between that LAN and other networks such as the Internet. A benefit is sharing a printer or Internet connection.

**Q24.** Benefits include shared printers/files and faster communication. Risks include unauthorized access and privacy loss; use unique passwords, access permissions, and multi-factor authentication where available. Malware and outages are other risks; keep devices updated, use approved security tools, and maintain separate backups.
