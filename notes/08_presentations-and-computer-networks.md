## PowerPoint: prepare and deliver

A **presentation** communicates ideas to an audience; a **slide** is one page in the deck. Plan a beginning, a few logically ordered sections, and a conclusion before adding effects.

### Create a usable slide deck

1. Open a blank presentation or suitable template. Save early as `.pptx` with a clear filename.
2. Use a title slide, then add slides with **Home → New Slide** and choose a layout that matches each slide’s content.
3. Give each slide one main point. Use short phrases, readable text, consistent fonts/colors, and sufficient contrast.
4. Insert an image, shape, chart, or SmartArt from **Insert** only when it clarifies the message. Check image permission, source, quality, and alt text.
5. Use **Slide Sorter** to inspect order and **Slide Show** to rehearse. Check timings, spelling, charts, transitions, and whether media works on the presentation device.
6. Keep animation and transitions restrained; use them to direct attention, not as decoration. Save again and carry a backup copy using an approved method.

Use slide notes for speaking prompts rather than crowding the slide. Cite sources for facts, data, and images. Do not put sensitive information on a projected or shared slide.

## Network essentials

A **computer network** connects devices so they can exchange data and share services. A network **node** is a connected device. Common scales are **PAN** (personal), **LAN** (local site), **MAN** (city/metro), and **WAN** (large geographic area). The Internet is a global network of networks.

Network types may be **client–server** (central servers provide services to clients) or **peer-to-peer** (devices share directly). Common topologies include **star** (devices connect through a central switch/access point), **bus** (shared backbone), and **ring** (devices form a loop). Each has different cost, performance, and failure characteristics.

| Component | Role |
|---|---|
| NIC / wireless adapter | Connects a device to a network |
| Switch | Connects devices within a LAN and forwards local traffic |
| Router | Connects networks and directs traffic between them |
| Modem | Converts signals for a particular access link/service |
| Access point | Provides wireless access to a wired network |

**Bandwidth** is the capacity of a link; **throughput** is the rate actually achieved. Protocols are agreed communication rules: IP addresses devices/routes packets; TCP helps deliver data reliably; DNS resolves domain names; HTTP/HTTPS carries web traffic (HTTPS encrypts the connection to the site).

Networks enable communication and sharing printers, files, applications, and Internet access. Risks include outages, unauthorized access, malware, privacy loss, and congestion. Use approved networks, strong unique passwords, multi-factor authentication when offered, updates, and encrypted connections. Do not join unfamiliar Wi-Fi for sensitive work; avoid sharing personal data publicly. A network connection does not itself make shared data trustworthy or backed up.

:::mistakes
- A LAN describes a limited area; a WAN spans a wider area. The Internet is not the same thing as Wi-Fi.
- A switch connects devices within a network; a router joins/directs traffic between networks.
- In PowerPoint, animation affects objects on a slide; a transition is the change between slides.
- More effects do not automatically improve a presentation. Clarity, rehearsal, and accessible design matter more.
:::
