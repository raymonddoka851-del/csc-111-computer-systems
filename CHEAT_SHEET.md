# CSC 111 · Practical review

Use this as a short final-pass checklist, then practise without looking at your notes. Follow the links for explanations and worked examples.

## 1 · Foundations

- Trace **input → processing → output**, with storage supporting each stage.
- Distinguish data from information, hardware from software, and capacity from speed.
- Binary place values (right to left): 1, 2, 4, 8, 16, 32. For `1101₂`, add `8 + 4 + 0 + 1 = 13₁₀`.
- Review generations by technology: vacuum tubes, transistors, integrated circuits, microprocessors, then modern VLSI/parallel development.
- Ask whether a result is accurate, useful, ethical, and based on trustworthy input.

[Open note 01](notes/01_computer-systems-foundations.md)

## 2 · Hardware

- Input enters data; CPU executes instructions; RAM holds current work; secondary storage keeps files; output presents results.
- CPU = control unit + arithmetic/logic unit + registers. RAM is volatile; ROM/firmware is persistent; cache is very fast.
- OCR recognizes text; OMR detects marked boxes. A touchscreen is both input and output.
- Protect devices from heat, liquids, unsafe power, static, and unauthorized access.

[Open note 02](notes/02_computer-hardware-components.md)

## 3 · Software

- System software manages the computer; applications help users complete tasks.
- OS, driver, utility, and application are different roles. Compiler, interpreter, and assembler translate code differently.
- Algorithm: define input, process, output, test with a sample case.
- Malware: virus, worm, Trojan, ransomware, spyware. Keep software updated, back up, and report suspicious activity.

[Open note 03](notes/03_computer-software.md)

## 4 · Windows and files

- Startup: firmware checks hardware → boot device/loader → OS loads → sign-in.
- Create folder → use a clear filename → Save As to the correct location → Save changes → verify destination.
- Copy preserves original; move relocates it; shortcut points to it. Do not change extensions to convert files.
- Lock when stepping away; sign out to end a session; restart to reload Windows. Save first.

[Open note 04](notes/04_windows-and-operating-systems.md)

## 5 · Internet and email

- Internet = interconnected networks; Web = a service on it; browser displays pages; search engine helps find them.
- Evaluate author, evidence, date, purpose, and citations. Compare sources and cite what you use.
- Email: verify recipient, use specific subject, concise message, correct attachment; proofread before send.
- Cc is visible to recipients; Bcc hides addresses from one another. Verify unusual requests through a separate channel.

[Open note 05](notes/05_internet-and-email.md)

## 6 · Word

- **Save As** first; save regularly. Use heading styles, consistent paragraph formatting, and page breaks.
- Insert tables/images from the ribbon; preserve image proportions; add page numbers where needed.
- Review spelling and grammar, then proofread names/numbers and inspect print preview.
- Mail merge combines a template and recipient list: clean data → connect → insert fields → preview → finish carefully.

[Open note 06](notes/06_word-processing.md)

## 7 · Excel

- Cell `B3` means column B, row 3. Range `B2:B6` includes both endpoints.
- Formula starts with `=`: `=B2*C2`. Common functions: `SUM`, `AVERAGE`, `MIN`, `MAX`, `COUNT`.
- Relative `B1` changes when copied; absolute `$B$1` remains fixed.
- Sort complete records; filter to inspect; select labels and values before inserting a chart.
- Check formula bar and errors; save `.xlsx` to preserve workbook features.

[Open note 07](notes/07_spreadsheets-and-excel.md)

## 8 · PowerPoint and networks

- Slides should communicate one main point each; keep text readable, use consistent design, cite sources, rehearse.
- Network benefits: communication/resource sharing. Risks: access abuse, privacy loss, malware, outages.
- LAN = local site; WAN = wider area. Switch connects within a LAN; router directs traffic between networks.
- Use approved Wi-Fi, unique passwords, updates, and restrained sharing.
